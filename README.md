# Pressure Lab — Rajasthan Royals 2027

A static interactive dashboard exploring pressure-performance rankings from the supplied 2022–2026 IPL and T20I data, with methodology notes and auction-fit scouting hypotheses.

## View locally

Open `index.html` in a browser, or serve this folder with any static web server. The page redirects to `dashboard.html`.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose deployment from the `main` branch and `/ (root)`, then save. GitHub Pages will publish the static dashboard at the URL it provides.

The page is a static snapshot: it does not update automatically with live scores, auction news, availability, prices or roster changes. Raw CSV data and the supplied problem-statement PDF are excluded from this repository.
